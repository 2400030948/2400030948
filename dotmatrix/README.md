1. Put a square-ish photo of yourself into the `input/` folder (jpg, jpeg, png, or webp).
2. Install Pillow: `pip install pillow`
3. Run: `python dotmatrix/generate.py`
4. The output SVG will appear at `dotmatrix/output/dotmatrix_portrait.svg`.
5. Add that SVG to the main README.md in the same spot the old photo used to be (I will paste the embed code myself once generated).
